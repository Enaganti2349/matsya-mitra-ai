# 🌊 Matsya Mitra (మత్స్య మిత్ర)
**Coastal Voice Assistant for Fisherfolk & Coastal Families**

Built for **The Great Indian AI Internship Challenge** powered by **Gnani AI**.

---

## 🚀 About The Project
**Matsya Mitra** is a low-latency, code-mixed voice assistant designed to empower fisherfolk and coastal communities in India. It bridges the digital divide by enabling users to query real-time marine weather updates, cyclone warnings, and government welfare schemes seamlessly in **Telugu and Telglish**.

---

## 🛠️ Gnani AI Ecosystem Integration
This application leverages the complete Gnani AI stack:
1. **Prisma v3.0 (STT):** High-accuracy Speech-to-Text specialized for regional languages and code-mixed Telglish audio.
2. **Evon (Reasoning/LLM):** Intelligent intent identification and coastal safety reasoning.
3. **Timbre (TTS Beta):** Natural Text-to-Speech synthesis for audio response delivery.

---

## ⚙️ Tech Stack
* **Backend:** FastAPI, Python, HTTPX, Pydantic
* **Frontend:** Streamlit
* **AI APIs:** Gnani AI Vachana & Model Ecosystem
